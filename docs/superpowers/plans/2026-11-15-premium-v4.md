# Temp-Mail Premium v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan cleanly task-by-task following strict TDD (`node --test test/*.test.js`) and verification-before-completion.

**Goal:** Upgrade the Telegram Temp-Mail Bot and Mini App into an ultra-fast, minimal, native-feeling flagship experience with real-time SSE delivery, smart OS-clipboard OTP auto-copy, a Google Authenticator / 1Password-grade 2FA Vault, hardened state resilience for Render Free tier, and an intelligent, minimal Telegram bot — stripped of all runtime self-mutation and spaghetti patches.

**Architecture:**
- **Backend (`src/`, `index.js`)**: Clean ESM Node 20+ HTTP server + Grammy Telegram bot + multi-account Titan IMAP + Gmail poller + Puppeteer/CDP Auto-2FA automation engine. All runtime disk-patching (`index.js` line 34, `src/config.js` `V18_PATCH`), monkey-patched HTTP response hooks, and hardcoded credentials are removed. Real-time push updates flow over per-user Server-Sent Events (`src/events.js` -> `/api/events`) authenticated via short-lived HMAC tokens (`src/auth.js`), backed by O(1) deduped storage, working TTL expiration, and gzip-compressed static/JSON responses.
- **Telegram Bot (`src/ui.js`, `src/bot.js`, `src/notify.js`)**: Minimal, clutter-free HTML cards with preserved `test/ui.test.js` guarantees (`mailCard` `'smart'` 3-line layout, single green `copy_text` OTP button, CTA link logic), clean in-process active card tracking (no `bot.api.config` interception), dynamic multi-domain switching (`config.domains` + Random mode), live `/codes` & `/2fa` refresh, `/inbox`, `/stats`, `/add2fa`, `/domain`, and upgraded inline mode (`@bot` generates mails, searches OTPs, and serves 2FA codes).
- **Telegram Mini App (`webapp/`)**: Modular vanilla ES + CSS (`index.html`, `styles.css`, `totp.js`, `qr.js`, `app.js`, deleting `webapp/v17.js`). Strictly gated to `Telegram.WebApp.initData`. Zero-bloat typography (`Plus Jakarta Sans` / `JetBrains Mono` / `Hind Siliguri`), 3 intentional visual skins (`minimal`, `obsidian`, `editorial`) with high-contrast curated palettes, 4 clean thumb-reachable views (`Inbox`, `2FA Vault`, `Hub`, `Settings` + conditional `Admin`), smart floating OTP auto-copy dock with multi-tier clipboard fallback + WebAudio chime + haptic feedback, pure-JS offline QR matrix renderer + Telegram `showScanQrPopup` integration + `otpauth-migration://` Google Authenticator batch parser + WebCrypto AES-GCM backup export/import.

**Tech Stack:** Node.js 24 (`node:test`, `node:assert/strict`, `http`, `crypto`, `zlib`), Grammy, ImapFlow, Mailparser, `@sparticuz/chromium`, vanilla ES modules + CSS custom properties + WebCrypto.
